# Plotterm — рукописный плоттер из браузера

Управление «писательной машиной» Dr.SONG (写字机) и любым плоттером на **GRBL 1.1**: вставляете текст —
программа раскладывает его по клеткам или линейкам, превращает в рукописные штрихи и печатает ручкой.
Ручка **сама опускается и поднимается по оси Z** — G-код содержит `G1 Z…` перед каждым штрихом и `G0 Z…` после.

Прошивку менять не нужно. Ничего не устанавливается, текст никуда не отправляется — всё считается на вашем компьютере.

## Как запустить

**Способ 1 — по ссылке (проще всего).** Откройте в **Chrome** или **Edge**:

> https://kofein123.github.io/Plotterm/

Страницу можно «установить» как приложение (значок ⊕ в адресной строке) — дальше она работает и без интернета.

**Способ 2 — локально.** Нужен [Node.js](https://nodejs.org) 22+ (ставится один раз).
Скачайте репозиторий (Code → Download ZIP), распакуйте и дважды щёлкните **`Запустить Plotterm.bat`**.
Откроется `http://localhost:8080`. Сборка не нужна — готовый код уже лежит в `www/`.

> Почему не просто открыть `index.html`? Браузер разрешает доступ к USB-порту только страницам с `https://` или `localhost`.

## Первый запуск: 4 шага

1. **Подключить.** Кнопка «Подключить плоттер» → выберите порт (USB-SERIAL CH340, обычно COM3).
   Bluetooth: спарьте `BtWriter` в настройках Windows — появится ещё один COM-порт.
2. **Калибровка → шаг 1 (ручка).** Кнопками `Z−` опустите ручку до касания бумаги → «Ручка касается».
   Поднимите на 1–3 мм кнопкой `Z+` → «Ручка поднята». Направление оси Z программа запомнит сама.
3. **Шаги 2–3 (лист).** Стрелками подведите ручку в левый верхний угол листа → «Здесь ноль».
   Затем в правый нижний угол → «Здесь край». Теперь каретка не выедет за лист, а программа знает, в какую сторону идут оси.
4. **Печать.** Вкладка «Текст» → вставить конспект → большая кнопка **ПЕЧАТЬ**.

Проверить всё без плоттера можно кнопкой **«Симулятор»** — виртуальная плата GRBL рисует результат прямо на предпросмотре.

## Что умеет

| | |
|---|---|
| **Связь** | Web Serial (USB и Bluetooth COM), 115200, опрос статуса 6–7 раз/с, потоковая отправка «по счёту символов» (буфер платы не переполняется, пауз между строками нет), автопереподключение |
| **Ручка (Z)** | калибровка касания и подъёма, нажим, плавное опускание, пауза после опускания, замер времени подъёма |
| **Безопасность** | границы листа (печать не стартует, если текст за краем — место подсвечено красным), СТОП = пауза движения → сброс → ручка вверх без потери положения, ручка поднимается на паузе, после ошибки и обрыва |
| **Продолжение** | после СТОПа, ошибки или обрыва USB — «Продолжить с места остановки»; «Повторить с…» — выбрать букву на листе и допечатать с неё |
| **Шрифты** | ГОСТ тип А и Б (однолинейные, кириллица, латиница, казахские ә ғ қ ң ө ұ ү һ і), **свой почерк** — рисуете буквы мышью/стилусом по 3–5 вариантов, импорт однолинейных SVG-шрифтов |
| **Почерк** | высота, наклон, интервалы, «живость» 0–10 с зерном (повторяемо), чередование вариантов букв |
| **Бумага** | A4, тетрадь в клетку, в линейку, свой шаблон; привязка строк к линиям сетки; поля, левая/правая страница, поворот 180° для оборота, «дописать с N-й строки» |
| **Текст** | переносы по слогам, по ширине, красная строка, `# заголовок`, `__подчёркнуто__`, степени `x^2` и индексы `a_{12}`, `√`, `===` — новая страница; импорт .txt, .md, .docx; проверка орфографии браузером |
| **Печать** | несколько страниц с паузой «смените лист» (звук + уведомление), сухой прогон с поднятой ручкой, обвод рамки, скорость на ходу 50–150 %, профили «черновик / обычный / аккуратный» |
| **Ещё** | SVG-рисунки и готовый G-код, экспорт G-кода, терминал с журналом, таблица $-настроек с пояснениями (изменение — только с подтверждением и копией $$), профили под предмет, статистика расхода ручки, экспорт/импорт всех настроек |

### Горячие клавиши
`Пробел` — пауза/продолжить · `Esc` — СТОП · стрелки — перемещение (удержание — непрерывно) · `PgUp`/`PgDn` — Z · `Ctrl+P` — печать.

### Разметка текста

```
# Заголовок по центру
Обычный абзац с красной строкой.
                                  ← пустая строка = пропуск строки
Формулы: E = mc^2, a_1 + a_{12}, √x. __Подчёркнуто__.
===                               ← новая страница
```

## Как это устроено

```
текст ─► вёрстка (строки, переносы, страницы, живость) ─► штрихи в мм на листе
     ─► план (упрощение, порядок штрихов, склейка, границы) ─► G-код с Z
     ─► стример GRBL (счёт символов, статус, пауза/стоп/продолжение) ─► плата
```

| Папка | Что внутри |
|---|---|
| `src/grbl/` | протокол GRBL, Web Serial, очередь со счётом символов, выполнение задания, симулятор |
| `src/core/` | разметка, переносы, вёрстка, калибровка (бумага ↔ станок), планировщик и G-код |
| `src/fonts/` | шрифты и достройка казахских букв |
| `src/ui/` | интерфейс (своя маленькая реактивная библиотека, без зависимостей) |
| `www/` | готовое приложение (собранный JS) — его и открывает браузер |
| `tests/` | тесты: вёрстка, G-код, и сквозные прогоны на виртуальной плате |

Разработка: `npm install` (только TypeScript), `npm run watch` и `npm run serve`; тесты — `npm test`.

## Про машину

GRBL 1.1 (Grbl_Esp32, станок `BtWriter`), ESP32 + драйверы A4988, моторы X, Y1/Y2, Z (ручка).
Шаги: X/Y 80, Z 65 шаг/мм. Концевиков нет (`$20=$21=$22=0`) — поэтому ноль ставится калибровкой.
После выключения питания плата забывает положение: программа замечает это при подключении и просит повторить шаги 2–3.

Если плата перезагружается при каждом подключении: «Ещё» → «Не трогать DTR/RTS».
