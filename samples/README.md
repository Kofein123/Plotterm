# Стенд качества почерка

```
npm run sample                      # все тексты × ГОСТ Б и Пропись, тетрадь в клетку
npm run sample -- --font propis --text samples/texts/lecture-1.md --paper a4 --live 5 --seed 3 --all
```

Результат — в `samples/out/` (не коммитится): `*.svg`, `*.png` (если установлен playwright) и `report.md` с метриками.
Параметры: `--font gost-a|gost-b|propis` (через запятую), `--paper grid|ruled|a4`, `--live 0–10`, `--seed N`,
`--text файл`, `--all` (все страницы, а не только первая), `--out папка`.

## Тексты

| Файл | Что проверяет |
|---|---|
| `texts/lecture-1.md` | обычный конспект: заголовок, абзацы, формулы, сокращения, подчёркивание |
| `texts/pangram.txt` | все буквы, заглавные, цифры |
| `texts/punct.txt` | знаки препинания, кавычки, скобки, «т. е.», диапазоны |
| `texts/repeat.txt` | одно слово и одна буква много раз подряд — видно ли, что это копии |

## Метрики (`src/core/quality.ts`)

- **Разнообразие букв** — насколько отличаются соседние экземпляры одной буквы (без учёта сдвига), в % x-высоты.
- **Разнообразие формы** — то же после совмещения поворотом и масштабом (расстояние Прокруста, 0…1).
  Ноль значит «та же буква, только повёрнута» — именно это глаз читает как машину.
- **Излом на стыках** — угол между касательными, где буква переходит в соединение и обратно; больше 25° видно глазом.
- **За полями** и **нет в шрифте** — должны быть нулём.

Пороги в `tests/quality.test.ts` — текущий уровень. Каждое улучшение почерка поднимает их, а не опускает.

## Слепой тест (на бумаге)

1. Напечатать `lecture-1.md` на плоттере на тетрадном листе.
2. Тот же абзац переписать от руки на таком же листе той же ручкой.
3. Показать оба листа 3 людям по отдельности, не говоря, где какой: «какой написан машиной и почему?»
4. Записать ответы и причины («буквы одинаковые», «стыки угловатые», «строка слишком ровная», …) в PR этапа.

Цель этапа 3 ТЗ: минимум половина людей не уверена или ошибается.
